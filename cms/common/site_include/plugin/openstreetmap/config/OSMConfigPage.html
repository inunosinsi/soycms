OpenStreetMapの設置方法

Leaflet - a JavaScript library for interactive maps

</body>の直下に

<!-- cms:module="openstreetmap.osm_lib" --><!-- /cms:module="openstreetmap.osm_lib" -->

を挿入する。


上記で挿入したCMSモジュールの下の行に

<!-- cms:module="openstreetmap.osm_init" --><!-- /cms:module="openstreetmap.osm_init" -->

を挿入する。


bodyタグ内で地図を出力したい箇所に

<div id="map"></div>

を挿入する。


例：headタグ内にstyleタグを挿入

<style>
html,
body{height:100%;}
#map {
	z-index:1;
	width:100%;
	height:100%;
}
</style>

2の<cms:module="openstreetmap.osm_init"タグの下に

<!-- cms:module="openstreetmap.osm_script" -->$blogUri=blog<!-- /cms:module="openstreetmap.osm_script" -->

を挿入する。

$blogUri=文字列の箇所にはブログページを作成した時に指定したアドレスを入れます。

※アドレスが空の場合は / (スラッシュ)を指定してください。


ブログブロック内(b_block:id="entry"やb_block:id="entry_list")で使用できるタグ一覧
osm:id タグ 説明
osm_lat すべて 記事に登録した緯度(latitude)を出力
osm_lng すべて 記事に登録した経度(longitude)を出力
osm_label すべて 記事に登録したラベルを出力
osm_icon img 記事に登録したアイコンの画像を出力
osm_icon_filename すべて 記事に登録したアイコンのファイル名を出力
osm_icon_path すべて アイコン画像のファイルパスを出力
osm_icon_label すべて アイコンに登録したラベルを出力
osm_icon_hash すべて アイコンのファイル名から作成したハッシュ値を出力
